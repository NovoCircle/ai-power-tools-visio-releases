# AI Power Tools for Microsoft Visio — Releases

Public release artifacts for [AI Power Tools for Microsoft Visio](https://store.novocircle.com/visio/) by [NovoCircle](https://novocircle.com).

## Installation

**Claude Desktop:** Download `AI-Power-Tools-for-Microsoft-Visio.mcpb` from the [latest release](../../releases/latest) and drag it into Claude Desktop.

**VS Code:** Download `ai-power-tools-visio.vsix` from the [latest release](../../releases/latest) and install via `Extensions: Install from VSIX...`.

## Licensing

A subscription is required. Purchase at [store.novocircle.com/visio](https://store.novocircle.com/visio/). After purchase you will receive a license key by email — enter it in the extension settings to activate.
